# E-Commerce-Sales-Analytics-PowerBI
Interactive Power BI dashboard analyzing e-commerce sales, customers, products, profitability, marketing, payments, delivery and returns.

## Project Overview

This project is an interactive Power BI dashboard created to analyze e-commerce business performance across sales, products, customers, profitability, marketing, payments, delivery, returns, and customer experience.

The dataset contains more than 138K orders and approximately 25K customers covering the period from 2021 to 2025.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Excel / CSV

## Dashboard Pages

1. Executive Overview
2. Product Analysis
3. Customer Analysis
4. Sales & Profit Analysis
5. Delivery, Returns & Customer Experience
6. Marketing & Payment Analysis

## Key KPIs

- Total Revenue: 177M
- Gross Sales: 190M
- Total Profit: 76M
- Total Orders: 138K
- Total Customers: 25K
- Profit Margin: 43%
- Average Order Value: 1.28K
- Return Rate: 6.9%
- Cancellation Rate: 6.1%

## Key Analysis

- Revenue and profit trends
- Product and category performance
- Customer segmentation
- Customer lifetime value
- New vs repeat customers
- Marketing channel performance
- Campaign performance
- Payment method analysis
- Delivery performance
- Return reasons and return rates
- Customer ratings and sentiment
